# 26.3 互通服专用资源（仅互通核心三件套）
# 用途：App 搭建 mcVersion == 1.26.3 的互通服时，从此目录 / Release 拉取 Geyser / Floodgate / ViaVersion。
# 互通服在 App 中仅支持 26.3 一个版本（geyserSupported = ["26.3"]），这些版本须与 26.3 后端严格匹配。

Geyser-Spigot.jar     Geyser      2.12.1-b1279    互通核心：基岩版 <-> Java 版桥接（含 aarch64 WebRTC 原生库）
                      —— 体积 52MB 超过 GitHub 文件树单文件上传上限，单独发布在仓库 Release「v1.26.3-geyser」：
                         https://github.com/likesugar/MC_fuwuqi/releases/download/v1.26.3-geyser/Geyser-Spigot.jar
Floodgate-Spigot.jar  Floodgate   2.2.5-SNAPSHOT  Java/基岩账号桥接（floodgate key 由同服生成）
ViaVersion-5.12.1.jar ViaVersion  5.12.1          版本桥接（5.12.2 不支持 26.3，会刷 "no compatible versions"，切勿升级）

注意：
- 7 个通用管理插件（Vault / LuckPerms / WorldEdit / WorldGuard / CoreProtect / Multiverse-Core / uSkyBlock）
  不属于本目录，它们跨版本通用，统一由 App 从 plugins-v1 Release 拉取（适用于 1.21.x ~ 26.3 区间的插件服）。
- OpenSSL 原生库（libcrypto.so.3 / libssl.so.3）与 MC 版本无关，不在此目录，仍走 bridge-assets 下载。
